## 1. 谁写年报，谁承担责任

年报由上市公司编制和披露。公司及相关责任人依法对信息披露承担责任；会计师事务所对年度财务报表实施审计并出具审计报告。

这里要分清对象：年报不只有财务报表，还可能包含行业分析、经营计划、风险因素、治理情况等。不能把“财务报表经过审计”扩展成“年报中每句话都获得了相同程度的审计保证”。

即使数字真实，管理层对未来的判断也可能落空。因此，阅读时至少分开三类信息：已经发生的事实、管理层的解释、对未来的预测或目标。

## 2. 审计到底能保证到什么程度

审计师通过检查证据、实施函证、观察、分析和抽样等程序，判断财务报表整体是否在所有重大方面按适用准则编制并公允反映相关情况。

“重大”指可能影响使用者判断的问题，并不是每一分钱都逐笔查验。“合理保证”是较高程度的保证，但受到抽样、估计、证据性质和串通舞弊等固有限制，不是绝对保证。[财政部发布的相关审计准则说明](https://www.mof.gov.cn/gkml/caizhengwengao/wg2022/wg202203/202206/P020220623585359615986.pdf)解释了审计总体目标和保证边界。

| 常见审计意见 | 入门理解                                                           |
| ------------ | ------------------------------------------------------------------ |
| 无保留意见   | 对财务报表整体形成了符合适用准则要求的肯定意见，不代表没有任何错误 |
| 保留意见     | 存在重大但不广泛的问题，或相应审计证据不足，需具体看保留事项       |
| 否定意见     | 已识别错报的影响重大且广泛，财务报表整体不能按要求公允反映         |
| 无法表示意见 | 因无法取得充分适当证据等情况，不能对报表整体发表审计意见           |

带强调事项段或涉及持续经营重大不确定性的报告，也需要阅读相关段落。不能只搜索“无保留”三个字后跳过后文；这些段落与修改审计意见的含义并不完全相同。

## 3. 企业真的可能制造虚假年报吗

可能。失真可能来自错误，也可能来自故意舞弊，例如虚构收入、提前确认收入、隐瞒负债或虚增货币资金。是否构成违法，需要事实调查和相应认定。

一个已经公开查明的例子是：证监会在对中天运会计师事务所的处罚决定中指出，美尚生态 2017—2019 年年报存在虚假记载、重大遗漏，而相应年度财务报表此前均取得标准无保留意见审计报告。这说明审计和监管机制可以追责，却不能保证问题永远不会发生。[来源：证监会行政处罚决定书〔2024〕13 号](https://www.csrc.gov.cn/csrc/c101928/c7467928/content.shtml)。

不能由此反过来得出“所有年报都没用”。正式披露仍是重要的信息基础，只是需要保持与证据相称的信任。

## 4. 普通投资者可以怎样交叉核对

先找到原始材料：交易所的信息披露栏目、依法披露的公司公告及报告全文。行情软件摘要和自媒体解读适合定位问题，重要结论仍要回到原文。

| 看到的现象                       | 接下来查什么                         | 不能直接得出的结论       |
| -------------------------------- | ------------------------------------ | ------------------------ |
| 利润持续增长，经营现金流长期较弱 | 应收款、收入确认政策、回款及业务模式 | “一定造假”               |
| 应收账款或存货增长快于收入       | 客户集中度、账龄、减值、库存周转     | “这些资产全是假的”       |
| 净利润很好，扣非利润较弱         | 出售资产、补助、投资收益等来源       | “所有非经常性收益都违法” |
| 审计机构变更或意见异常           | 变更原因、前后任说明、具体审计事项   | “换所就等于有问题”       |
| 收到监管问询或更正公告           | 问询内容、回复证据、更正影响         | “收到问询已被认定违法”   |

这些检查用来缩小不确定性，无法替代专业审计或调查。发现自己解释不了的重大疑点时，“暂时不参与”也是可执行的判断，不必强行给出买或卖的结论。

## 5. 记录结论时保留证据层次

可以将每条研究笔记写成四句话：

1. **事实**：报告中具体披露了什么，位于哪页、哪张表，单位是什么。
2. **解释**：公司怎样解释这一变化。
3. **判断**：自己认为这一变化可能意味着什么。
4. **缺口**：还缺少什么信息，什么证据会改变判断。

例如：“应收账款增加 40%”是可核对的事实；“因为公司放宽信用政策”如果只是自己的推测，就不能写成事实。让 AI 总结时也应保留这些区分，而不是让流畅文字掩盖证据不足。
