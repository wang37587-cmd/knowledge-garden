> [!abstract] 30 秒掌握
>
> - **利润表解释一段时间里公司怎样赚到或亏掉利润。** 收入不是利润，利润也不是当期收到的现金。
> - **资产负债表说明某个时点公司有什么、欠什么，以及账面上归属所有者的净额。**
> - **现金流量表解释一段时间里现金怎样流入和流出。** 有利润的公司也可能缺钱还债。
> - 三张表需要互相核对，并结合附注理解，不能只看一个净利润数字。

## 1. 三张表分别回答什么

| 报表       | 直白的问题                     | 时间属性       |
| ---------- | ------------------------------ | -------------- |
| 利润表     | 这段时间生意做得怎么样？       | 期间，例如一年 |
| 资产负债表 | 到这一天，家底和欠账分别多少？ | 时点，例如年末 |
| 现金流量表 | 这段时间实际进出多少现金？     | 期间，例如一年 |

可以把利润表看作经营成绩，资产负债表看作时点清单，现金流量表看作现金收支记录。这个比喻便于记忆，但会计确认和分类有正式规则，不能拿个人记账方法机械替代。

财务报表还包括所有者权益变动表和附注等。本章先从最常用的三张表入门，阅读真实报告时不能把附注省掉。

## 2. 利润表：卖了多少与赚了多少不同

假设一家家电公司全年销售商品，符合收入确认条件的营业收入是 1 亿元；相关成本、费用和所得税等合计 9,000 万元，且没有其他损益项目：

**净利润 = 1 亿元 − 9,000 万元 = 1,000 万元。**

这个例子故意把很多项目合并了。真实利润表需要进一步区分营业成本、销售费用、管理费用、研发费用、财务费用、减值损失、投资收益及所得税等。

几个基础概念：

- **营业收入**：公司日常经营活动形成的收入，不等于所有现金流入。借来一笔钱不是营业收入。
- **毛利**：营业收入减去营业成本。它还没有扣完经营中的各类费用，不能当成最后赚到的钱。
- **净利润**：按会计规则确认各项收入、费用和损益后形成的最终利润。
- **归母净利润**：在合并报表中归属于母公司股东的净利润，需与少数股东享有的部分区分。
- **扣非净利润**：扣除非经常性损益后的利润指标，有助于观察利润是否主要来自持续经营，但不是“绝对真实利润”的认证。

如果利润增长主要来自一次性出售房产，不能直接假设明年还会同样增长。

## 3. 为什么赚了 1,000 万元，现金却减少

沿用上面的极简例子，再假设全年 1 亿元销售中只收回 7,000 万元，其余 3,000 万元尚未收款；9,000 万元相关支出全部以现金支付。为突出差异，假设没有期初往来款、增值税及其他现金或非现金调整。

**经营现金净流入 = 7,000 万元 − 9,000 万元 = −2,000 万元。**

于是，公司同时出现净利润 1,000 万元和经营现金净流出 2,000 万元。差别主要是确认了收入，但客户还没付钱。

这 3,000 万元未收回的货款形成应收账款。应收账款是要求客户付款的权利，不是已经躺在银行里的现金；如果客户还不起，可能需要确认信用损失。

应收账款增加并不自动证明造假。赊销安排、业务增长和收款周期都会影响它，但需要进一步看客户、账龄、坏账准备和后续回款。

## 4. 资产负债表：净资产不是现金余额

另设一个独立的年末例子，单位均为万元：

| 资产           |   金额 | 负债及所有者权益 |   金额 |
| -------------- | -----: | ---------------- | -----: |
| 现金等货币资金 |  1,000 | 借款             |  4,000 |
| 应收账款       |  3,000 | 应付账款         |  2,000 |
| 存货           |  2,000 | 所有者权益       |  4,000 |
| 厂房设备等     |  4,000 |                  |        |
| 合计           | 10,000 | 合计             | 10,000 |

核心关系是：**资产 = 负债 + 所有者权益。**

所有者权益也常被称为净资产：10,000 − 6,000 = 4,000 万元。它是账面余额，不是可以立即拿出来分给股东的 4,000 万元现金，更不是公司的股票市值。

存货可能卖不掉，应收款可能收不回，设备出售可能有折价。因此账面净资产也不等于清算时股东最终能拿回的钱。

这家公司资产负债率为 6,000 ÷ 10,000 = 60%。但仅凭 60% 不能判断是否危险，还要看行业特点、债务期限、利息、现金流及资产质量。

## 5. 现金流要看来自哪里

| 分类     | 典型现金流                       | 观察重点                           |
| -------- | -------------------------------- | ---------------------------------- |
| 经营活动 | 收货款、付供应商及员工等         | 主业能否持续产生现金               |
| 投资活动 | 买设备、建厂、出售长期资产等     | 公司在扩张还是处置资产，效果如何   |
| 筹资活动 | 借款、还款、发行股份、分配股利等 | 资金从谁那里来，未来有哪些支付压力 |

公司通过借款使现金增加，不代表经营变好；投资现金净流出可能来自合理扩张，也不自动是坏事。判断必须连同用途与后续效果。

如果近期有 3,000 万元债务到期，却只有 1,000 万元可动用现金，即使利润表显示赚钱，也可能面临支付压力。是否能缓解，还取决于后续回款、其他可变现资产和可获得的融资等。

## 6. 初读财报先做四件事

1. 确认单位、报告期间和报表范围，是合并报表还是母公司报表。
2. 连续看三至五年收入、利润和经营现金流，避免只看一年。
3. 对异常变化查附注，例如应收账款、存货、减值、关联交易和债务到期安排。
4. 把数字翻译成经营问题：收入为什么增长，利润为什么没跟上，货款为什么收不回来？

三年或五年是学习时便于观察趋势的窗口，不是能保证识别风险的神奇期限。金融企业等行业的报表结构和业务逻辑还需要专门学习。
